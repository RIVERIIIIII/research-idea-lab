部分重建与状态续接

对齐到同一已确认位置N，选择前缀长度k。

历史状态前缀：0 … k−1后缀：k … N−1
信息来源U保存的模型段输入记录A保存的会话KV
恢复路径U → BA → B
目标端动作重放前缀，恢复对应KV导入对应位置的KV

前缀重建　＋　后缀复制　→　一致状态验证　→　继续生成

两支路允许并行，但需共同满足网络、计算与显存约束。

同一模型、快照、位置和精度约定；不存在的记录不能视为可用能力。

借鉴[1]输入记录恢复与[2]前缀/后缀分割；本状态续接协议仍需具体接口和正确性核验。

k=0为完整KV复制，k=N为全部从输入记录重建。这里重建的是一个模型段的历史KV，不是重算整段用户回答。两部分覆盖互不重叠的历史位置，导入后验证并切换。

本方案是有条件的协议推导，不是Petals或ctHO已实现本系统的事实；特别不能与EdgeFlow按层使用activation投影的机制混为一谈。

优化目标

首先缩短受影响请求的最大恢复停顿，再控制增量光资源占用。

重建比例改变传输需求；光资源可行性反过来影响目标和重建选择。

不以任意加权的目标包装收益。第一目标最小化最大停顿，在同停顿值下再优化光资源。模型可以覆盖同一故障影响的多请求，不在线假定剩余输出长度已知。

详细有限计划0-1模型见research/proposals/X02-midterm-2026-10-26/model-notes.md。指定路径、策略和时间网格内的参考最优，不声称连续原问题全局最优。

恢复停顿与关键约束

T恢复 = T决策 + max{T服务就绪, T前缀支路, TKV支路}
+ T验证切换 + T下一有效输出

约束必须保证
状态正确同一快照与位置，前后缀不重不漏，在途输出去重
计算与显存参数、KV、输入缓冲及重建工作区均有可用资源
光网络可行路径可达，频槽连续且沿路一致，调制可达，资源不冲突
服务保障停顿不超过剩余预算，恢复后的完整推理链满足性能约定

计入状态准备、传播、传输、重建及配置；检测前等待也消耗用户停顿预算。

两条状态支路中的配置、准备、传播和数据传输均计入，前缀支路还含重建。共有成本不要重复相加，独立支路可以并行。停顿从用户最后有效输出到下一有效输出统计，不能在检测后重新起表而漏算等待。

首版QoT用距离可达性与保守裕度近似，不宣称实现完整GN干扰模型。最终组合和其他业务最低保障也要检查。

拟议求解流程

  1. 读取故障与状态快照剩余光资源、状态记录、目标算力/显存、服务预算
  2. 保留原地恢复，并生成接替候选联合考虑目标、重建长度及所需状态/服务路径
  3. 由停顿预算推导最低容量需求映射到满足连续性和调制可达性的频槽配置
  4. 检查资源冲突并搜索恢复计划支配裁剪、有限宽度联合搜索及必要回退
  5. 输出可执行计划，或明确保障不可满足小规模以完整枚举或MILP作参考，比较解质量与求解开销
算法为拟研究路线，尚未实现；同样计入其决策耗时，不预设性能或近似保证。

关键不是“先跑一个恢复算法，再跑一个重建算法”，而是每个候选都包含完整任务动作和光配置，容量需求由恢复预算反推。多请求共享资源时，按槽和时段检查冲突。

支配裁剪必须比较资源占用向量，不能仅凭路径长度删除可能避开竞争的计划。搜索宽度、路径数量及k的块粒度可控制复杂度，但需报告漏解和最优差距。

相对经典基线的条件性优势

比较同一目标与可执行光配置下的固定全KV接替和部分重建。

T全KV = c + aV + βN

T(k) = c + max{aH + αk, aV + β(N−k)}

α：单位前缀记录传输与重建成本；β：单位KV传输成本。
aH、aV：各支路固定开销；c：共同的其他恢复成本。

严格改善的充分条件

存在合法k，使两条状态支路均早于全KV搬运完成，且新增开销未抵消节省。

要求状态可执行、资源公平、服务连接不主导；不证明优于所有经典保护方法。

这是线性成本与独立可行支路下的书面推导，非实测规律。若平衡点k*=(aV+βN−aH)/(α+β)在(0,N)，连续模型中可得严格状态准备收益；整数k需检查相邻值。如果服务连接就绪更慢，要再取max；若新方案有额外成本Δ，还需扣除。

最优计划保留全部经典可行动作时，扩大可行集只能使相同目标的最优值不增。但不能把它当实际启发式或在线求解总耗时不劣的证明。证据：classical-baseline-proof.md。

当前进展与待验证问题

已完成的方案准备

  • 故障与业务场景界定
  • 已有工作与恢复动作对照

拟形成的研究内容

面向推理状态续接的联合恢复模型，以及满足服务时限的光资源配置与求解方法。

X02以研究方案形式汇报，算法实现与性能实验尚未完成。

不把中期方案当作已完成的第二点成果。导师不要求已有阶段结果，但最终论文仍需完成与主张相匹配的验证。实验主要基线可为适用的经典保护/恢复与固定状态搬运，最近邻作书面差异对照。
