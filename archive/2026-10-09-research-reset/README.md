# 历史研究归档

归档日期：2026-10-09。归档前 Git HEAD：`cd70d563d16c61c5f666cd2fe6270ece2362d906`。

本目录保存新一轮研究重置前的论文清单、笔记、检索报告、综述、gap、hypothesis、候选、回查、探索、验证代码与数据，以及当时的推进状态。内容未经批量改写，不代表当前研究结论。

`manifest.json` 记录每个文件的原路径、归档路径、字节数和 SHA-256；所有文件移动后均核对哈希。旧文件中的 `research/...`、`papers/...` 路径是当时的仓库路径，回查时按本归档目录解析。本文档和 manifest 为归档时新建文件，不在文件清单内。

## 使用规则

- 默认研究入口为仓库中的 `research/research-brief.md` 与 `research/current-status.md`。
- 不将本目录批量输入新一轮 survey、gap 或 hypothesis，不直接恢复旧 corpus。
- 按需回查原文证据；复用时重新确认与当前 brief 的关系，保留稳定论文身份和 evidence ID。
- 旧 KEEP、REVISE、REJECT、HOLD 和人工决定保留其历史含义，不自动转化为本轮结论。
- 笔记序号保留于 `papers/note-registry.json`；归档不释放已经分配的序号。

原始 PDF 缓存和人工收集的论文仍保留在原位置，不因归档自动纳入新 corpus。
