# 常用比较维度

只选择当前论文卡片有明确证据、且对路线区分有帮助的维度。

## 问题设定

- 研究对象和任务目标
- 输入、输出与约束
- 系统或网络环境假设
- 优化目标

## 方法设计

- 核心机制与控制层级
- 集中式、分布式或去中心化方式
- 静态规划、在线学习或运行时自适应
- 通信、计算、内存与资源异构的处理方式

## 数据与评测

- dataset、topology、workload、baseline、metric
- 模拟、原型或真实部署
- 消融、敏感性与可扩展性证据

## 局限

- 作者明确承认的适用边界
- 依赖的假设、数据或硬件环境
- 证据范围和可迁移性

不要机械填满所有维度；未知项标明未提供，而不是推测。
